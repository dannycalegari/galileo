To the Reader. //

This Figure, that thou here seest put, //
It was for gentle Shakespeare cut; //
Wherein the Graver had a strife //
with Nature, to out-doo the life: //
O, could he but have drawne his wit //
As well in brasse, as he hath hit //
His face; the Print would then surpasse //
All, that was ever writ in brasse. //
But, since he cannot, Reader, looke //
Not on his Picture, but his Booke. //

B. I.

An Epitaph on the admirable Dramaticke Poet, W. SHAKESPEARE. //

What neede my Shakespeare for his honour'd bones, //
The labour of an Age, in piled stones, //
Or that his hallow'd Reliques should be hid //
Under a starre-ypointing Pyramid? //
[...] //
And so Sepulcher'd in such pompe dost lie, //
That Kings for such a Tombe would wish to die.

THE TEMPEST. //

Actus primus, Scena prima. //

A tempestuous noise of Thunder and Lightning heard: Enter a Ship-master, and a Boteswaine. //

Master. Bote-swaine. //
Botes. Heere Master: What cheere? //
Mast. Good: Speake to th' Mariners: fall too't, yarely, or we run our selves a ground, bestirre, bestirre. //
Exit.
