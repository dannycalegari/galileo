# Stand-in scripts for tools/check.py (part 3). Each scenario runs tools/play.sh on a COPY of a
# fixture save (tools/check/fixtures/), one run after another on the same copy, and checks the
# output of each run. To add one, write a block and, if it needs a new place in the game, put a
# save in fixtures/ (make it with tools/play.sh on a scratch copy, then copy the save here).
#
#   scenario NAME
#     about TEXT              one line: what it guards
#     fixture FILE | -        a save in tools/check/fixtures/ ("-": a new game, from the choosing screen)
#     run COMMANDS            the commands of tools/play.sh, as one string (a few words: use _ for a space)
#     expect TEXT             the output of the run above contains TEXT
#     absent TEXT             ... does not contain TEXT
#     expect-re REGEX         ... has a line matching REGEX
#     file-expect REGEX       the save file, after the run above, has a line matching REGEX
#     file-absent REGEX       ... has none
#     exists SUFFIX           a file beside the save (".bak") exists
#   end
#
# Fixtures: paris_start (the farm start's first morning, 10:00 on 15 June 1632, in the street at
# Paris), paris_sorbonne (the same, inside the Sorbonne, 37 livres), florence_landini (inside
# Landini's printing house, Florence), stockholm (just landed from Danzig), arcetri (inside the
# convent of San Matteo), rome_ch4_worse (chapter IV of the worse branch, inside the Villa Medici, 18 July 1634).
# paris_packet: the prologue's second morning, at the Pomme de Pin with Mersenne's packet for the south (and a post packet).
# paris_start_fraction is paris_start with the time 600.125.
